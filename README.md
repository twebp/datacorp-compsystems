# DataCorp Computer Systems Website Redesign

A responsive redesign of the DataCorp Computer Systems website,
a local computer repair and technology services company in Valdosta, Georgia.

## Project Goals

- Modernize the existing website
- Improve navigation and readability
- Create a responsive layout for desktop, tablet, and mobile
- Improve visual hierarchy and accessibility

## Built With

- HTML5
- CSS3
- JavaScript
- Visual Studio Code

## Features

- Responsive design
- Service category navigation
- Modernized branding
- Mobile-friendly layout
- Interactive prototype

## Project Status

Currently in development.
